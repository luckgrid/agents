# tmux mapping

A nonempty `TMUX` identifies a tmux context, not permission to control every
pane. Check the installed version and documentation, then resolve the exact
session and pane under the environment's rules.

tmux can arrange panes, send input, and capture output. It does not provide
native agent identity, lifecycle status, reliable completion, or approval
detection. Report those capabilities as unavailable; visible output and a
result file are evidence to inspect, not an automatic status detector. Any
input must be explicitly authorized for the responsible operator and target.

This mapping has no tmux worktree lifecycle. Use the environment's authorized
worktree workflow and do not claim that pane operations create or remove Git
worktrees. Use bounded briefs and durable result files; inspect results and
report uncertainty.
