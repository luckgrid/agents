# Wiki

Follow the wiki's own README and its named authorities. The shared template is
`wiki-structure.md` in Luckgrid's wiki-nest; it decides if this skill differs.
Read the entry points in [orient](references/orient.md) before making changes.
If the authority is unavailable, say so and do not invent a conflicting rule.

## Modes

| Mode | Reference | Use |
| --- | --- | --- |
| `orient` | [orient](references/orient.md) | Learn a wiki's scope and current position before acting |
| `write` | [write](references/write.md) | Add or revise a wiki page in the shared template |
| `record` | [record](references/record.md) | Preserve an episode, source evidence, or owner intent |
| `decide` | [decide](references/decide.md) | Record an owner's decision and its durable rule |
| `state` | [state](references/state.md) | Keep the single current-position register accurate |
| `crystallize` | [crystallize](references/crystallize.md) | Turn a session into a linked, complete record |
| `lint` | [lint](references/lint.md) | Check structure, links, IDs, and Markdown |
| `query` | [query](references/query.md) | Find and answer from wiki evidence |

## Rules that always hold

- Follow the wiki's authorities and local instructions. This public skill gives
  general methods; it does not override a wiki's template or owner decisions.
- Keep evidence types distinct: current/source material, historical evidence,
  accepted decisions, proposals, status or delivery reports, and private runtime
  evidence are not interchangeable.
- Preserve source wording and historical evidence when the wiki requires it.
  Label quotations, summaries, hypotheses, and unverified claims accurately.
- Never add secrets, credentials, private runtime paths, or identifying account
  and agent details to a public wiki.
- Cite the pages supporting an answer. Search results and snippets are leads;
  read the source page before relying on a claim.
