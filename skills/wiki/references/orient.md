# Orient

Before editing, identify the wiki's scope and the authority for the question.

1. Read the repository root README and the target wiki's README.
2. Read its `records/STATE.md`, then follow the pages it names for the current
   task. Read relevant architecture, decisions, proposals, guides, and source
   material in their own context.
3. Check dates and status. A newer proposal does not replace an accepted
   decision; a delivery report does not prove a lasting rule; STATE is the
   current register, not a substitute for its underlying evidence.
4. Identify whether evidence is live/source, historical, a decision, a
   proposal, status/delivery, or private-runtime evidence. Do not merge these
   kinds when summarizing.
5. If an authority is missing or conflicting, report the gap and ask the owner
   or maintainer. Do not silently choose a rule.

For a question that does not require a change, use [query](query.md). For a
change, use the relevant [write](write.md), [record](record.md), [decide](decide.md),
or [state](state.md) mode, then [lint](lint.md).
