# Crystallize

Turn a completed session or conversation into a durable record without
pretending that the record contains anything the source did not establish.

1. Identify the session's purpose, dates, participants by appropriate public
   role, and source material. Separate direct observations, owner intent,
   decisions, proposals, and outcomes.
2. Capture every durable decision, unresolved question, material result, and
   next step. Link existing evidence instead of copying large sources.
3. Keep owner intent faithful. Quote only when explicitly requested or when
   preserving a source's existing quotation; otherwise attribute a concise
   summary. Do not turn agent recommendations into owner choices.
4. Label delivery and status claims with their source and date. A command run,
   draft, or local result is not a merge, publication, or approval.
5. Exclude secrets and private-runtime details from public records. Retain
   historical evidence as required by the wiki; do not silently delete or
   rewrite it.
6. Add frontmatter, links, and an index entry if the wiki requires one. Update
   STATE only for a verified change in current position.

Check the result with [lint](lint.md). If it contains an accepted choice, make
or link the distinct decision record using [decide](decide.md).
